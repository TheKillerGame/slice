# Slice

A swipe game for phones. Fruit gets thrown up from the bottom of the screen:
swipe through it to slice it. Let 3 fruit fall or slice a bomb and the run is
over.

By **RisingForce**.

## Play

Open `index.html` in any browser, on a phone or a computer. It's a single file
with no install, no server and no internet needed (the fonts are embedded and
the sounds are made in code). Swipe with a finger, or drag with the mouse.

## Features

- Waves that throw more fruit, more bombs and faster salvos as you go
- Slice 3 or more fruit in one swipe for a combo bonus
- Every 10th wave is a boss: a giant pineapple that floats in the middle while
  you hack at it before its timer runs out (if it gets away you lose a life
  and it comes back)
- Beating a boss takes you to a new world:
  - **orchard** (waves 1-10): the basics
  - **beach** (11-20): golden fruit worth +5
  - **sunset** (21-30): fruit flies in from the sides
  - **night** (31-40): twice the bombs
  - then the worlds loop with every twist at once
- 8 blades, each with its own trail and power, won by beating bosses:
  - **classic**: no tricks
  - **katana** (boss 1): longer trail, combos start at 2 fruit
  - **frost** (boss 2): fruit fall 20% slower
  - **flame** (boss 3): extra-wide blade
  - **guardian** (boss 4): start with 4 lives
  - **lucky** (boss 5): 2 points per fruit
  - **shield** (boss 6): survive one bomb each run
  - **rainbow** (boss 7): 2 points per fruit and 4 lives
- Coins: +1 per wave, +10 per boss, +1 per golden fruit, plus mission rewards
- Store: power-ups used one per run (extra life, double coins, bomb shield)
  and background patterns
- 16 missions with progress bars and coin rewards
- Credits with YouTube and Discord
- Everything is saved: best score and wave, bosses beaten, stats, coins,
  missions, blade, store items and mute
